# v0.3.7 验证记录


## v0.3.7 Win+D 自定义过渡

通过 Windows Raw Input 的键盘 INPUTSINK 接收 Win+D，不注册/吞掉系统快捷键，不安装低级键盘钩子、不轮询键盘、不保存输入内容。识别左右 Windows 键、按键重复和额外修饰键。挂件自行维护 Win+D 隐藏状态；再次按下淡入恢复，手动收起不会误恢复，手动托盘恢复会重置该状态。设置对话框打开时保持原系统行为。

复用短暂快照动画，分别淡出/淡入 160 毫秒。只在动画帧期间保持临时快照位于桌面上方，避免 Explorer 的显示桌面将它直接盖住；主窗口的置顶、位置、尺寸及无任务栏图标行为不变。恢复快照从卡片内容和窗口背景合成，解决隐藏 WPF Window 生成空图的问题。动画结束、取消或退出均释放窗口、快照及 Rendering 订阅。

- 158 项确定性检查通过，覆盖左右 Win+D、长按去重、松键，以及 Ctrl/Shift/Alt 组合不误触。
- 隔离实际 WPF 窗口验证淡出/淡入中间透明度与非空画面、快速连按、托盘恢复取消动画、手动隐藏不误恢复、动画中退出；原托盘收起/退出生命周期检查仍通过。测试不发行情请求或写个人设置。
- 点击隔离测试控制器调用 Windows Shell ToggleDesktop，与自定义动画同时运行：前台变为 Progman，标准控制器实际最小化，动画中间透明度 0.494，快照 Z 序仍在桌面之前；Shell UndoMinimizeALL 与恢复动画联动后保留位置/置顶/纯托盘模式，临时窗口释放。
- 实际后台 WM_INPUT 消息正常到达挂件并完成解码。以上将快捷键识别、输入接收、Shell 显示桌面和动画分别验证，未通过自动化发送实体 Win+D；实体快捷键的完整视觉时序、多显示器切换尚未人工验收。
## v0.3.6 退出响应与收起动画

退出先隐藏挂件及托盘图标，再等待后台清理；Codex 查询进程的启动/结束移出 UI 线程，主动取消时不再等待正常退出宽限。同时处理清理已同步完成时的 Closing 重入，以及已释放查询令牌的重复取消问题。

收起使用临时 WPF 快照进行 160 毫秒淡出，遵循 Windows 动画开关，完成或取消后关闭临时窗口并释放内容；主窗口保持原有不透明渲染。动画时长不包含快照与窗口准备开销。

- 同一挂起查询在启动 500 毫秒后取消：旧发布包耗时 2580 毫秒，修复后 562 毫秒，消除了约 2 秒宽限等待（均含取消前等待）。这是本机短样本，不作为所有机器的耗时保证。
- 隔离实际 MainWindow 检查：空闲/查询中的退出约 50–150 毫秒；窗口与托盘立即隐藏，重复退出不会重入清理，退出中恢复不会重新显示窗口。
- 收起/恢复连续三次，验证中间透明度、结束后的临时窗口释放及位置/尺寸/置顶保留；中途恢复、动画中退出、已收起时退出均通过。查看了淡出中间帧；未做多显示器/DPI 切换验收。
- 146 项自动化检查通过，取消挂起查询的上限断言由 6 秒收紧为 2 秒；原有正常查询、超时、重试和错误恢复检查保持通过。

## v0.3.3 短暂查询失败重试

实际捕获 `account/rateLimits/read` 返回内部错误 `-32603`，随后的账户查询确认 ChatGPT 登录存在，后续额度查询恢复成功。没有取得该次错误的具体底层原因，不能推断为登录失效或确认是网络故障。

为额度读取的 `-32603` 增加一次延迟 2 秒重试，先完成失败进程清理再启动下一次；其他错误和超时保留原处理。重复内部错误最多两次尝试，取消会中止延迟，错误提示不再一律要求检查登录。

- `dotnet run --project DeskMonitor.Tests -c Release`：146 项检查通过，新增短暂内部错误恢复、持续错误尝试次数限制、重试延迟取消，以及其他错误不重试检查。更新后的客户端真实查询成功，未输出额度数值。
- 旧版截图的通用错误文字无法确定失败原因；本版失败后可悬停查看阶段与错误码。

## v0.3.2 用量刷新恢复

排查时连续三次本机查询均成功，未复现用户当时的外部服务失败。故障注入确认了一个会阻塞后续刷新的代码路径：app-server 退出后，其子进程持有 stderr 管道，原实现仍无限等待日志读取结束。修复后取消日志读取，并对退出与日志清理分别设定有限等待；保留原有每分钟查询周期，不增加高频轮询或常驻进程。另补充缺失/非法额度的 InvalidDataException 处理，失败保留旧值并明显标记，不将失败数据当作新结果。

- `dotnet run --project DeskMonitor.Tests -c Release`：140 项检查通过，包含真实子进程故障注入；覆盖继承日志管道、RPC 错误、提前退出、缺失额度、取消、20 秒请求超时，以及失败后的再次查询。继承管道测试在修改前失败、修改后通过。
- 实际 MainWindow / UsageCard 的隔离 WPF 集成检查通过：失败保留旧值并淡化，刷新按钮恢复，重复点击不并发启动，每分钟调度后恢复，取消不延迟下次读取；三档尺寸均正确显示旧值/正在更新/首次读取失败。测试不修改个人设置。
- 修复后客户端成功读取本机 Codex 额度，测试输出不记录额度数值。网络断开、登录失效和上游不可用仍可能导致单次查询失败；未进行长期断网或 24 小时稳定性验收。

## 资源与验证边界

程序无浏览器内核、第三方 NuGet 依赖或持续动画。现货最多一条连接，所有 USDT/USDC/TradFi 合约共用一条连接；曲线每 5 秒采样，最多保留一小时。资金费率复用合约连接，每 3 秒推送。

.NET/WPF 仍有常驻内存开销。此前三行情与用量场景的短样本工作集约 195–248 MiB、私有提交约 137–186 MiB；样本运行时长和桌面遮挡状态不完全一致，不能据此承诺长期资源占用或认定优化因果，且不含用量查询子进程。

发布包依赖 .NET 8 Desktop Runtime，未做自包含运行时或安装程序。未完成 24 小时断线、不同机器、多显示器/DPI 切换的长期验收；未实际注销/重启 Windows 验证自启动。程序未进行代码签名。
