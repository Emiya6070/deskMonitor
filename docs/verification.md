# v0.3.3 验证记录

## v0.3.3 短暂查询失败重试

实际捕获 `account/rateLimits/read` 返回内部错误 `-32603`，随后的账户查询确认 ChatGPT 登录存在，后续额度查询恢复成功。没有取得该次错误的具体底层原因，不能推断为登录失效或确认是网络故障。

为额度读取的 `-32603` 增加一次延迟 2 秒重试，先完成失败进程清理再启动下一次；其他错误和超时保留原处理。重复内部错误最多两次尝试，取消会中止延迟，错误提示不再一律要求检查登录。

- `dotnet run --project DeskMonitor.Tests -c Release`：146 项检查通过，新增短暂内部错误恢复、持续错误尝试次数限制、重试延迟取消，以及其他错误不重试检查。更新后的客户端真实查询成功，未输出额度数值。
- 旧版截图的通用错误文字无法确定失败原因；本版失败后可悬停查看阶段与错误码。

## v0.3.2 用量刷新恢复

排查时连续三次本机查询均成功，未复现用户当时的外部服务失败。故障注入确认了一个会阻塞后续刷新的代码路径：app-server 退出后，其子进程持有 stderr 管道，原实现仍无限等待日志读取结束。修复后取消日志读取，并对退出与日志清理分别设定有限等待；保留原有每分钟查询周期，不增加高频轮询或常驻进程。另补充缺失/非法额度的 InvalidDataException 处理，失败保留旧值并明显标记，不将失败数据当作新结果。

- `dotnet run --project DeskMonitor.Tests -c Release`：140 项检查通过，包含真实子进程故障注入；覆盖继承日志管道、RPC 错误、提前退出、缺失额度、取消、20 秒请求超时，以及失败后的再次查询。继承管道测试在修改前失败、修改后通过。
- 实际 MainWindow / UsageCard 的隔离 WPF 集成检查通过：失败保留旧值并淡化，刷新按钮恢复，重复点击不并发启动，每分钟调度后恢复，取消不延迟下次读取；三档尺寸均正确显示旧值/正在更新/首次读取失败。测试不修改个人设置。
- 修复后客户端成功读取本机 Codex 额度，测试输出不记录额度数值。网络断开、登录失效和上游不可用仍可能导致单次查询失败；未进行长期断网或 24 小时稳定性验收。

## v0.3.1 趋势下拉框点击修复

窗口拖动逻辑原先只识别 ComboBox，未识别独立 Popup 视觉树内的 ComboBoxItem；点击时间选项会被拦截为拖动。现将 ComboBoxItem 排除在拖动区域外。

已在实际 MainWindow 的隔离测试窗口通过桌面鼠标点击复现修复前的问题，并验证修复后 BTC 卡片选择 15 分钟、ETH 卡片独立选择 5 分钟。事件日志确认选项点击不再被处理为拖动，两项偏好经序列化往返保留，重新创建卡片恢复 15 分钟。测试禁用真实网络与个人设置写入。修复适用于共用该控件的中、大卡片，不添加最小尺寸的选择入口。

## 资源与验证边界

程序无浏览器内核、第三方 NuGet 依赖或持续动画。现货最多一条连接，所有 USDT/USDC/TradFi 合约共用一条连接；曲线每 5 秒采样，最多保留一小时。资金费率复用合约连接，每 3 秒推送。

.NET/WPF 仍有常驻内存开销。此前三行情与用量场景的短样本工作集约 195–248 MiB、私有提交约 137–186 MiB；样本运行时长和桌面遮挡状态不完全一致，不能据此承诺长期资源占用或认定优化因果，且不含用量查询子进程。

发布包依赖 .NET 8 Desktop Runtime，未做自包含运行时或安装程序。未完成 24 小时断线、不同机器、多显示器/DPI 切换的长期验收；未实际注销/重启 Windows 验证自启动。程序未进行代码签名。

测试截图、临时代理工具、个人设置备份及本机历史日志均不随公开仓库或 Release 上传。
